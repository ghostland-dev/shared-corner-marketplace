# Kiwiiz

Peer-to-peer rental marketplace for items and services.

## Features

- Listings near you
- Supabase back-end

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Supabase

## Getting Started

```bash
git clone https://github.com/ghostland-dev/shared-corner-marketplace.git
cd shared-corner-marketplace
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview

> The committed `.env` contains placeholder values only. Replace them with your own credentials locally.
